\section{Introduction}

Entanglement distillation and quantum network tomography(QNT) are two important  components of quantum network. 


Quantum network tomography is important technique to estimate the each link-parameter of a quantum network. After determining the parameters of each link, we can estimate the enatanglement directly without some state tomography techniques, construct more reliable network and select more effiencient entanglement distillation protocol just like the  \cite{Miguel_Ramiro_2018}. 


Entanglement distillation is essential for quantum key distribution  , 
Unfortunately, repeated entanglement swapping operations needed for establishing long-distance communication exponentially degrade the end-to-end fidelity.
Entanglement distillation protocols can be used to sup-
press this fidelity loss by transforming a number of
noisy entangled states into a smaller number of high-fidelity states using only local operations and classical
communication



Existing QNT methods are  mainly based on state tomography which requires local measurements at monitors which has the same settings as distillation protocol.
